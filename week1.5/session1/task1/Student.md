# Student Class

## Attributes
StudentId
StudentName
StudentDOB
StudentTimetable
StudentParents
StudentAddress
## Behaviour

StudentId - return StudentId as string
StudentName - return name as string
StudentDOB - return name as string
StudentTimetable - return timetable as array or enter a day or time for specific part of timetable if day or time empty then return that whole day or week or whatever
StudentParents - Return array with multiple parents details
StudentAddress - return array of strings of different lines of the student address
